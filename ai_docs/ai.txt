# AI instructions for cursor_window_title_plugin

Author: Matthew Schinkel

## Project purpose

VS Code / Cursor extension that sets `window.title`, the workspace folder display name, and Recents/jump-list labels from:

- `.env/window_title.txt` (first non-empty line)

when a workspace opens.

## Stack

- TypeScript
- VS Code Extension API (`engines.vscode`)
- Compiles to `out/extension.js`

## License & repository

- License: MIT (`LICENSE`)
- GitHub: https://github.com/mattschinkel/Visual-Studio-Code-Window-Title-Plugin.git
- Marketplace publisher id in `package.json`: `matthew-schinkel`

## Important constraints

- Cursor marketplace “plugins” (rules/skills/hooks) cannot set the OS/IDE window title. This project is a real editor extension.
- Cursor’s custom title bar may ignore `window.title`; prefer `"window.titleBarStyle": "native"`.
- Title path is a **folder** `.env` containing `window_title.txt` (not a root `.env` key/value file).
- Do not use HTTPS for local websites in other projects; not applicable here.
- Keep `progress.md` and `instructions.txt` updated.
