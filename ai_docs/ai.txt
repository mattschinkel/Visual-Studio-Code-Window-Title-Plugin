# AI instructions for window-title (Window Title Plugin)

Author: Matthew Schinkel

## Project purpose

VS Code extension that sets `window.title`, the workspace folder display name, and Recents/jump-list labels from:

- `.vscode/window_title.txt` (first non-empty line)

when a workspace opens.

## Stack

- TypeScript
- VS Code Extension API (`engines.vscode`)
- Compiles to `out/extension.js`

- Extension id: `MatthewSchinkel.window-title`

## Important constraints

- This is a real VS Code extension (not an editor “plugin” pack of rules/skills/hooks).
- Some editors’ custom title bars may ignore `window.title`; prefer `"window.titleBarStyle": "native"`.
- Title path is `.vscode/window_title.txt` (not `.env` and not a key/value env file).
- Do not use HTTPS for local websites in other projects; not applicable here.
- Keep `progress.md` and `instructions.txt` updated.
